# 2026-09-26 — Day 0: scaffold

**What landed**

- Chose the name: Rize.
- Decided the three things everything else depends on: Node/TS monorepo (ADR-0001), non-custodial for all rails (ADR-0002), Solana Pay reference keys + transaction-request fee split (ADR-0003).
- Prisma schema v0.1 — the `Invoice` state machine is the heart of it, and `Event` is append-only so analytics never need a migration.
- Bot boots with `/ping` and `/setup`; API has `/health` and webhook stubs; dashboard is a placeholder page.
- CI: lint, typecheck, test, build against a Postgres service.

**What surprised me**

- Solana Pay's transfer-request URL can't split to two recipients. The transaction-request flavour can, but it means wallets have to reach our API — that's a real dependency to design around (rate limits, uptime).
- Stripe Connect makes the card side genuinely non-custodial with one parameter (`application_fee_amount`). Less work than expected.
